# Brand

## Name

**SERSHI** — always uppercase in the wordmark and product copy. It is its own
name, not an acronym, and not a reference to any fictional assistant.

- Positioning: **SERSHI — your intelligent desktop companion.**
- Description: _An open-source AI agent that lives on your computer._
- Possible tagline: _Think. Speak. Act._

## Personality and voice

Intelligent, concise, calm, warm, capable, confident, non-intrusive.

| SERSHI says                                                   | SERSHI doesn't say                                   |
| ------------------------------------------------------------- | ---------------------------------------------------- |
| "You're using 12.0 GB of 32.0 GB memory (38%)."               | "Great question! 😊 Let me check that for you!!"     |
| "Opening applications isn't available yet — it's planned for v0.1." | "Oops! Something went wrong."                   |
| "I couldn't complete that. The system didn't return the information — try again in a moment." | "Error 0x000041AF" |

No emojis, no roleplay, no fake emotions, no filler. Answer first; explain only
when useful. Honest about limits.

## Logo direction

The mark is SERSHI's own geometry: a luminous core, one tilted orbit and a single
satellite (`apps/desktop/brand/sershi-mark.svg`). It should read at 16 px as "a
point of light with an orbit". Final logo design is deferred; the current mark is a
working identity.

- Wordmark: Geist, weight ~560, tracking 0.32em, uppercase.
- The mark takes the current state color inside the product.
- **The core is the strongest brand signature.** It stays abstract: no face,
  no eyes, no mascot or robot — one bright point, orbits and light. Two
  bright points that could read as eyes are a defect.
- **Approval mark:** inside the confirmation window only, a small shield
  around the core with the words "SERSHI approval" and an amber hairline
  frame. It signals "this is SERSHI's decision window"; it is not an
  operating-system security indicator and must never imitate one.
- One icon family: 16 px line icons, 1.5 px stroke, round caps
  (`components/shell/icons.tsx`), and 12 px status glyphs
  (`components/core/StateGlyph.tsx`). No emoji or mixed symbol sets.

## Color identity

Near-black with a blue undertone; ice white and signal cyan as the identity
colors; aura violet for thought; ember reserved for attention. See
[DESIGN_SYSTEM.md](DESIGN_SYSTEM.md#color).

## Prohibited references

Do not use or imitate: the names of fictional AI assistants from films or comics
(anywhere — branding, code, assets, docs), superhero or arc-reactor imagery, Marvel-style HUDs, Tron grids, cyberpunk neon overload,
RGB gamer styling, or any copyrighted character. SERSHI's identity comes from its
own core-and-orbit language.
